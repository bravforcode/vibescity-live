# Contributing

Thank you for considering contributing! This project is part of the bravforcode portfolio — professional, production-oriented, and welcoming to quality PRs.

## How to Contribute

1. Fork the repo and create a feature branch (`feat/my-feature`).
2. Follow existing code style:
   - **JS/TS**: `biome check --write .` (preferred) or `prettier` + `eslint`
   - **Python**: `ruff check .` + `ruff format .`
3. Add or update tests for your change.
4. Ensure CI passes (`bun test` or `uv run pytest -q` or `npm test` as applicable).
5. Open a PR with a clear description and linked issue if applicable.

## Commit Messages

Use conventional commits: `feat(scope): description`, `fix(scope): description`, `chore: ...`, `docs: ...`
